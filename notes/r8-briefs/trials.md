## The item
- **A Trial a week:** derived from the ISO week key like the Cup, the same for everyone, so a friend's link and a ghost from the same week race the same rules. Its identity is the twist, named in a few plain words a player reads in a second ("Mirrored Ember in a blizzard, gates only from the survival family", "Finish Sakura without a get-up"). It must play differently from that week's Cup, not be a second Cup.
- **Its own medal:** bronze, silver and gold targets a player can see before riding, fair and the same for everyone, set from that week's trial itself (for example from its generated field's runs, as the Cup's field is generated in the worker), never hand-tuned per week. A medal is kept in the save per week and shows wherever medals show; what it pays (Rider Rank experience, an Almanac line) follows the spine's rules and adds no new currency.

- **The run:** the HUD names the twist once at the start and the medal's next target, in what the HUD already has (the stage line, a beat card); results say which medal and how far from the next.
